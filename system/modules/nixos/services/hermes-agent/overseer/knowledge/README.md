# Overseer knowledge

This directory holds persistent Markdown notes and reports maintained by Overseer.
It starts fresh and does not import Pierre's existing Obsidian notes. Quartz is
the planned private reading interface; the Markdown files remain the source.

Use descriptive filenames, Markdown links and ISO dates. Keep durable reference
notes separate from dated reports. Record sources, verification dates and open
questions. Credentials and raw private conversations do not belong here.

Native Hermes memory remains under `/opt/data/memories`; it contains the compact
context needed at session start. This directory holds the longer material that
Overseer can read when relevant and point Pierre to.
